# Branding Assets

Logo PNG resmi disimpan sebagai **pt-kuda-prima-logo.png**. Jangan mengubah rasio atau warna
logo tanpa persetujuan. Salinan aset Flutter harus identik dengan source ini; ganti keduanya
secara terkontrol jika source resmi diperbarui.

Source saat ini transparan dan berukuran 120 x 79 px. Ukuran tersebut cukup untuk development
pada tampilan konservatif, tetapi harus diganti dengan PNG transparan minimal 512 px atau SVG
resmi sebelum pembuatan aset store. Jangan melakukan AI redraw atau upscale sebagai pengganti
source merek yang benar.
